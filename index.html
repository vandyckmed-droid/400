    Scores are cross-sectional percentiles within the current S&P MidCap 400 — a rank against peers, not a return forecast. See how the score tested →

    How the score works

    1. 12–1 momentum. Total return on dividend- and split-adjusted closes over the 12 months ending one month ago. The most recent month is skipped to sidestep short-term reversal.
    2. 6–1 momentum. Same idea over the trailing 6 months, again ending one month ago.
    3. Volatility adjustment. Each leg is divided by the annualised standard deviation of daily log returns measured over that same formation window, so a steady climb outranks an equally large but erratic one.
    4. Cross-sectional percentile. Each leg is ranked against every other name in the chosen peer set on the same day and mapped to 0–100.
    5. Blend. Final score = 50% × 12–1 percentile + 50% × 6–1 percentile.

    Peer sets

    MidCap 400 is the index itself. Extended 650 adds the 250 smallest S&P 500 members by market cap, so a name is measured against everything of roughly its size rather than against an index boundary. Within sector ranks a name only against its own GICS sector, which strips out the sector bet the whole-universe ranking otherwise takes — useful if you already control sector weights elsewhere. Both S&P 500 membership and the market caps that pick the tail are point-in-time, so a past bar reflects the universe as it stood that day.

    The history chart re-runs the full cross-section at each month end, so a bar shows where the name stood against its peers on that date. The peer set is today's index membership throughout, which introduces some survivorship bias in older bars. Data: Financial Modeling Prep. Not investment advice.
